SHUDDH MILK Android Project - Version 2

इस संस्करण में जोड़ा गया:
- ऐप खुलने पर स्थानीय Admin PIN स्क्रीन (पहली बार डेमो PIN 1234)
- सेटिंग्स से 4 अंकों का PIN बदलना
- पूरा JSON बैकअप डाउनलोड करना
- JSON बैकअप से डेटा रीस्टोर करना
- पहले के दूध/किसान/ग्राहक/बिक्री/पेमेंट फीचर बरकरार

APK बनाने के लिए:
1. Android Studio में यह फ़ोल्डर खोलें।
2. Android SDK Platform 35 और JDK 17 इंस्टॉल होने दें।
3. Build > Build Bundle(s) / APK(s) > Build APK(s) चुनें।
4. APK: app/build/outputs/apk/debug/app-debug.apk

महत्वपूर्ण सीमाएँ:
- PIN केवल स्थानीय डेमो लॉक है, मजबूत सुरक्षा/OTP प्रमाणीकरण नहीं।
- डेटा अभी डिवाइस पर ही रहता है; क्लाउड डेटाबेस या अलग-अलग मोबाइलों में लाइव सिंक नहीं है।
- क्लाउड सेवा जोड़ने के लिए Firebase/Supabase प्रोजेक्ट, उसके कॉन्फ़िगरेशन और सुरक्षा नियम आवश्यक होंगे।
- असली भुगतान, SMS/WhatsApp, ब्लूटूथ प्रिंटर, FAT/SNF आधारित प्रमाणित रेट कैलकुलेशन अभी इंटीग्रेट नहीं हैं।
- कारोबार में उपयोग से पहले सभी हिसाब और बैकअप की जाँच करें।
